# Nexara Studio

A modern, responsive web design and development agency website built to showcase Nexara Studio's services, projects, and approach to creating websites for real businesses.

## 🌐 Live Demo

[**Visit Nexara Studio**](https://nexarastudio.github.io/Nexara-Studio/)

## ✨ Features

- Modern dark-themed agency design
- Fully responsive layout
- Smooth scrolling navigation
- Scroll reveal animations
- Interactive contact form feedback
- Portfolio showcase
- Service sections
- Business-focused design
- Mobile-friendly layouts

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts — Poppins
- Git & GitHub
- GitHub Pages
